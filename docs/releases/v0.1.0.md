# Kex Lab 0.1.0

Initial versioned integration bundle for evaluating Kafka operations with the
published Kafka, Explorer, Kex-anHarness and AutoTune images, plus optional
SpectraLLM and observability profiles.

## Included

- Guided lightweight demo without Spectra or model downloads: `make demo-lite`.
- Provisioned Grafana dashboard for metrics endpoint availability, AutoTune
  traffic/errors, measured consumer lag and JVM usage.
- Internal Python-standard-library lag adapter; missing measurements remain
  unavailable rather than becoming zero lag.
- Editable SVG and Mermaid overview alongside the original architecture image.
- Markdown/JSON reports with actual container image IDs, registry digests,
  interface links, current health and recorded per-run Kafka assertions.
- Isolated integration checks, exact Kafka offset deltas and read-only MCP
  diagnosis paths inherited from the validated Lab configuration.

## Validation and limits

Run `make check`, `make integration-smoke` and `make observability-smoke` for the
repository, Kafka scenario and real dashboard/metrics checks. A running container,
a successful scrape and a successful model/tool invocation are distinct evidence.
The Agent reasoning step requires a configured provider; Spectra inference and
model downloads are optional and are not exercised by these smoke tests.
AutoTune's pinned image supports amd64; both Spectra indices support amd64/arm64.
This is a local evaluation bundle with one broker, not a production deployment.

## Bundle contents

The release preparation command adds the exact Git commit, `versions.env`, a
machine-readable bundle manifest and SHA-256 checksums. Credentials, reports,
cloned components and model artifacts are excluded from the source archive.

## Publishing

Prepare from the reviewed, clean commit with `make release-prepare`. Publish the
`v0.1.0` tag only after the feature PR is merged into `main` and its checks pass.
The release workflow verifies the tag matches `VERSION`, belongs to `main`, and
passes repository and isolated runtime checks before creating the GitHub release.
